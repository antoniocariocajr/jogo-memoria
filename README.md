Um jogo da memória clássico com temática de super-heróis, desenvolvido com tecnologias web modernas. O projeto apresenta um visual "Dark Mode" premium, animações fluidas e lógica de jogo totalmente funcional.

## ✨ Funcionalidades

- **🎮 Mecânica de Jogo Completa**: Sistema de combinação de pares, verificação de vitória e reset.
- **🎲 Embaralhamento Real**: Algoritmo Fisher-Yates para garantir partidas sempre diferentes.
- **🎨 Visual Premium**: Design moderno com efeito de vidro (Glassmorphism), gradientes e bordas arredondadas.
- **⚡ Animações**: Efeitos de virada de cartas (Flip 3D) e transições suaves.
- **📊 Estatísticas**: Contador de movimentos e pares encontrados em tempo real.
- **📱 Responsivo**: Adapta-se perfeitamente a telas de desktop e dispositivos móveis.
- **🏆 Telas de Feedback**: Telas dedicadas para Início de jogo e Vitória.

## 🚀 Como Jogar

1. Abra o arquivo `index.html` em seu navegador.
2. Clique no botão **"Iniciar Jogo"** na tela de boas-vindas.
3. Clique nas cartas para virá-las e tente encontrar os pares dos heróis.
4. O objetivo é encontrar todos os 8 pares com o menor número de movimentos possível!

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica.
- **CSS3**: Estilização avançada com Flexbox, Grid, Variáveis CSS, Animações e Media Queries.
- **JavaScript (ES6+)**: Lógica de jogo, manipulação do DOM e gerenciador de estados.
